# Project scope (summary of the supplied master brief)
Indore Prime Properties is a fictional Shuvi 360 portfolio brand, in English with Hindi support, INR and Asia/Kolkata. No fake RERA numbers, reviews, availability, or sale offers. Public demo uses noindex. Customer, owner and agent mobile interfaces share a secure backend and dedicated Neon PostgreSQL database.

## Roadmap
0. Repository, Next.js App Router, strict TypeScript, Tailwind, tracker, environment template, build.
1. Premium emerald/ivory/gold responsive public site, hero, cards, localities, contact and preview.
2. Neon, ORM, versioned migrations, authentication and backend role authorization.
3. Property CRUD, publication validation, media management, 25–30 clearly fictional listings.
4. Mobile app, saved properties/search, filters, comparison (max 3), EMI, profiles.
5. Real GLB/glTF viewer, orbit/zoom/fullscreen, camera presets, hotspots, sample villa, mobile fallback; no fake walkthrough.
6. 360 panorama upload/viewer, room navigation and tour builder.
7. Enquiries persisted to CRM, Kanban, assignment, notes, duplicate detection, rule-based matching.
8. Site visits, conflicts, agent dashboard, follow-ups, notifications, customer status.
9. AI studio: original media, manual GLB, provider adapters, asynchronous jobs, preview/review/approval before publication, accuracy labels.
10. Website assistant using database, UTM and conversion tracking, marketing dashboard.
11. Authorized WhatsApp/Instagram/AI calling, consent and opt-out, logs; no paid calls without approval.
12. Reports, private docs, branding editor, SEO, customer management and CSV.
13. PWA, safe cache, optimized image and 3D loading, low-end mobile/security tests.
14. Isolated demo center and full end-to-end workflow, production deployment and final documentation.

## Rules
No paid integration without approval; no secrets in git, no destructive migrations without approval, preview before production, server-enforced roles and organization isolation, no private CRM offline cache, no simulated successes. Manual GLB and actual panoramas before AI; clearly distinguish concept imagery, approximate reconstruction, floor-plan model and professionally verified model. Do not expose private owner contact or documents. Keep original media. Store blobs in object storage, not PostgreSQL. Test real browser 3D controls. Commit each phase and distinguish implemented from tested.
