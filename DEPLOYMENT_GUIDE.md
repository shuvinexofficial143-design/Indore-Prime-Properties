# Preview deployment guide
1. Import this repository into an authorized Vercel project. Deploy preview/advanced-completion as a preview, not production. Node.js 22, Next.js framework, default npm install and npm run build.
2. Provision a dedicated PostgreSQL database (e.g. Neon), never reuse another business database. Configure DATABASE_URL with sslmode=verify-full and run npm run db:migrate and npm run db:seed locally against that dedicated database. Migrations 001–015 are required for this revision. Bootstrap an authorized fictional demo owner locally and remove bootstrap values. See README.
3. Set DATABASE_URL and APP_ORIGIN in the preview environment; APP_ORIGIN must match the actual HTTPS preview origin exactly. Redeploy after configuration if necessary. Check /api/health, catalog, sign-in, admin dashboard, create a fictional draft, enquiry and visit, customer saved list and isolated sandbox. Do not use genuine personal data.
4. For uploads, provision a private S3-compatible bucket and least-privilege credentials, HTTPS endpoint. Set S3_BUCKET, S3_REGION, S3_ACCESS_KEY_ID, S3_SECRET_ACCESS_KEY and optional S3_ENDPOINT. Test a small image upload privately, owner review/publish, public gallery and denied cross-tenant access. Current per-file cap 3 MB; video support is limited to short compatible clips.
5. Optional Meshy: only after explicit billing authorization configure MESHY_API_KEY and MESHY_GENERATION_ENABLED=true; verify provider response and one authorized fictional source with consent. Optional OpenAI: configure OPENAI_API_KEY, OPENAI_PROPERTY_ASSISTANT_MODEL (a supported Responses structured-output model) and OPENAI_PROPERTY_ASSISTANT_ENABLED=true only after authorization. Per-request user consent required. Never expose keys to browser or Git.
6. Automation worker is local simulation only. Do not enable actual external messaging/calling without separate authorized accounts, provider permissions, consent/opt-out, signed webhooks and legal review. Optional internal worker requires AUTOMATION_WORKER_ENABLED and AUTOMATION_WORKER_SECRET plus an external scheduler; none is provisioned.
7. Verify mobile, performance, installation, security, accessibility, backups, monitoring, upload lifecycle, credentials and provider billing before any public launch. Keep noindex for the fictional demo. Do not merge to main until approved.
