# Database schema
Versioned migration 001_initial.sql: organizations, organization_settings, users (owner/agent/customer), sessions (SHA-256 token digests), login_attempts and properties. Organization-scoped unique property slugs, price in integer paise, status constraints and catalog indexes. Seed inserts eight fictional properties only into a dedicated demo organization; no credentials seeded. Migration runner uses transaction and advisory lock. App uses parameterized pg queries; owner overview scopes counts to authenticated organization. ORM deferred in favor of SQL migrations/pg for this initial implementation. Live Neon migration not applied because connector calls fail. CI uses disposable PostgreSQL 16. Future phases add media, CRM, agents, customers and booking tables; tenant-scoped foreign keys required.
